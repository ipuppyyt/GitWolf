Open source Git client

A fast, native Git client that stays in sync

GitWolf watches your repositories and shows every change the moment it happens, whether you made it here, in a terminal or in an editor. It uses the Git you already have.

What you get

Everything you do with Git, without the rough edges

Built natively for each platform. No web view, no jank, fixed rows and stable selection.

Always in sync

The window watches the working tree, index and refs. Changes made in a terminal or editor appear at once. There is no refresh button.

Stage by line

Stage, unstage or discard a whole file, a hunk or single lines. Commit and amend, with every hook output shown when a commit is refused.

History, rebase and conflicts

A branch graph with search, interactive rebase, a conflict resolver with side-by-side choices, cherry-pick, revert, bisect and blame.

Pull requests and CI

Sign in to GitHub, GitLab, Bitbucket, Gitea or Azure DevOps. Clone, open pull requests, and see check results on every repository tile.

Many repositories at once

A rail of repositories with live change badges. Press ⌘K to jump anywhere, and see open pull requests across all of them.

Undo and safety nets

Undo the last change, a checkout or a whole rebase. Browse the reflog. Discard and stash dialogs say exactly what will be lost.

Repository statistics

Commits per week, top contributors, hot and high-churn files, and who works in each folder.

Your Git, your credentials

Every action runs the system git, so your config and hooks apply. Tokens live in the system keychain, never in a URL or log.

Opens from the terminal

Install the gitwolf command and run gitwolf . to open the current folder. Links like gitwolf://open?path=… work too.

Install

Download GitWolf for Mac or Windows

Free, and updates install from inside the app.

Mac with Homebrew

One line, and no security prompt.

brew install --cask ipuppyyt/gitwolf/gitwolf

Mac, disk image

Get the latest .dmg, drag GitWolf to Applications and open it. macOS asks once, because the app is not notarised:

  1. System Settings > Privacy & Security > Open Anyway, or
  2. xattr -dr com.apple.quarantine /Applications/GitWolf.app

Windows 10 and 11

Download the Windows .zip, unzip it anywhere you can write to, and run GitWolf.App.exe. Windows may ask once (More info > Run anyway).

Trust

Open source, signed, and built in the open

The code is on GitHub under the MIT licence and builds from source. Each release is built by GitHub Actions from a tag, with checksums published next to the download. Updates are signed with a key only the maintainers hold, and the app refuses anything that does not verify. Read how releases are made.

Questions

Frequently asked questions

Is GitWolf free?

Yes. It is free and open source under the MIT licence.

Does GitWolf replace Git?

No. It runs the Git that is already installed on your computer, so your configuration, hooks and credentials behave exactly as they do in a terminal.

Which hosting services does it work with?

GitHub, GitLab, Bitbucket, Gitea and Forgejo (including Codeberg) and Azure DevOps, cloud or self-hosted. You can clone, open pull requests and see CI results.

Why does macOS say it cannot verify GitWolf?

GitWolf is not notarised, because notarisation needs a paid Apple Developer account. Choose Open Anyway in System Settings once. Installing with Homebrew skips this, and updates installed from inside the app never ask.

Is there a Linux version?

Not yet. GitWolf is built natively for each platform, and a Linux client is planned. Contributions are welcome.
