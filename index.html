GitWolf

A fast, clean, native Git client for Mac. Open source, always in sync, and it uses the Git you already have.

Download for Mac View on GitHub

macOS 15 or later · free · MIT licence

What you get

Always in sync

Changes made in a terminal, an editor or another tool show up at once. No refresh button.

Truly native

SwiftUI and AppKit, no web view. Fixed rows, stable selection, no jank.

Your Git, not ours

Every action runs the system git, so your config, hooks and credentials behave as usual.

Stage by line

Stage, unstage or discard whole files, hunks or single lines. Interactive rebase, conflicts, bisect and blame.

Your hosting, built in

GitHub, GitLab, Bitbucket, Gitea and Azure DevOps: clone, pull requests, issues and CI results.

Private by design

Tokens stay in your Keychain. Never in a URL, a command line or a log file.

Install

With Homebrew:

brew install --cask ipuppyyt/gitwolf/gitwolf

Or download the disk image from the latest release, drag GitWolf to Applications and open it. macOS will say it can't verify the app, because GitWolf is not notarised (that needs a paid Apple account). Allow it once:

  1. Open System Settings > Privacy & Security, scroll down and choose Open Anyway.
  2. Or run xattr -dr com.apple.quarantine /Applications/GitWolf.app in Terminal.

After that, updates install from inside the app. Each one is signed with a key only the maintainers hold, and the app refuses anything that does not verify.

Open from the command line

Install the gitwolf command from Settings, then:

cd ~/code/my-project
gitwolf .

Trust

GitWolf is open source and builds from source with swift build. Releases are built by GitHub Actions from a tag, and the checksums are published next to each download. Read how releases are made and signed.
